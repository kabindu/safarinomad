# Package photos

Every package has its own photo here, named after the package id in `js/data.js`
(for example `great-migration.jpg` is the Great Migration Safari). No photo is used twice.

**To use your own photo:** save it here with the same file name, replacing the old one.
Landscape, about 1400 × 930 px, JPEG under 400 KB works best. No code changes needed, and
visitors see the new photo straight away.
When every photo here is your own, delete `photo-credits.html`, its footer link in `js/layout.js`
and `credits.json`.

These preview photos are from Wikimedia Commons. 67 of the 104 are top-rated there ("Featured"
or "Quality" images, reviewed for sharpness, natural colour and composition); the rest are the best
available for places with no rated photos. Their licences allow commercial use as long as the
photographer is credited, which `photo-credits.html` does. `credits.json` holds the same list.
