# Package photos

One photo per savannah package, named after the package id in `js/data.js`
(for example `great-migration.jpg` is the Great Migration Safari).

**To use your own photo:** save it here with the same file name, replacing the old one.
Landscape, about 1400 × 930 px, JPEG under 400 KB works best. No code changes needed.
When every photo here is your own, delete `photo-credits.html` and its footer link in `js/layout.js`.

These preview photos are from Wikimedia Commons. 46 of them are top-rated there ("Featured" or
"Quality" images, reviewed by judges for sharpness, natural colour and composition). Their licences allow
commercial use as long as the photographer is credited, which `photo-credits.html` does.
